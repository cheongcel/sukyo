# 숙 계산 기준과 자료

## 방식

입력은 양력 날짜입니다. 일본 구력(kyureki) 날짜로 바꾼 뒤 월숙방통력의
해당 월 1일 숙을 기준으로 `day - 1`을 더하고 27로 나눈 나머지를 사용합니다.
1~12월 1일은 室/奎/胃/畢/參/鬼/張/角/氐/心/斗/虛입니다.
출생시간과 서버 시간대는 사용하지 않습니다. 한국/중국 음력과 일부 날짜가 다를 수 있습니다.

윤달은 같은 월의 표를 사용합니다. 예를 들어 2023-03-22는 윤2월 1일이며 奎宿,
2023-04-06은 윤2월 16일이며 亢宿입니다. 임의로 윤달 중간에 다음 월로 바꾸지 않습니다.

## 자료 출처와 재생성

- 구력 변환 자료: https://github.com/manakai/data-locale
- 고정 리비전: `241fa20712a179b2287d801bb30b51af227461e6`
- 파일: `data/calendar/kyuureki-map.txt`
- 설명: https://github.com/manakai/data-locale/blob/master/doc/calendar-kyuureki.txt
- 설명에 명시된 자료 계통: 일본 국립천문대 달력 DB, 20세기력, 21세기력 등.
- 2033/2034년은 원자료의 윤11월 정책을 따릅니다.
- 라이선스: 자료는 사용·복제·파생물 작성이 허가됩니다. 설명과 JSON에는 CC0도 명시됩니다.
  정확한 허가 문구는 `src/main/resources/calendar/SOURCE.txt`에 함께 보관합니다.
- 배정표: https://nakshatra.tokyo/pc/30.html
- 관계 기준: https://kosei-do.co.jp/details/senseiban.html

저장소 루트에서 `node scripts/generate-calendar.mjs`를 실행하면 고정 원본의
월 시작일만 추출합니다. 결과 CSV에 원본 URL과 SHA-256을 기록합니다.
1900-01-01부터 2100-12-31까지 지원하고 2101-01-29 경계를 포함합니다.
서버는 이 파일만 읽으며 인터넷 접속/천체력 다운로드가 필요 없습니다.

## 외부 비교 사례

2026-09-11에 https://kosei-do.co.jp/fortune/uranai.php 에 직접 입력하여 확인:

| 양력 | 기준 결과 |
|---|---|
| 2002-02-24 | 星宿 |
| 2002-02-25 | 張宿 |
| 2002-02-26 | 翼宿 |
| 1996-03-14 | 女宿 |
| 2023-03-22 | 奎宿 |
| 2023-04-06 | 亢宿 |
| 2023-04-19 | 婁宿 |
| 2023-04-20 | 胃宿 |
| 2024-02-09 | 室宿 |
| 2024-02-10 | 室宿 |
| 2024-02-29 | 房宿 |
| 1985-01-01 | 畢宿 |

이 사례들은 회귀 테스트에 들어 있습니다. 기준 사이트의 모든 날짜를 비교한 것은 아닙니다.
윤달/역법 정책이 다른 서비스에서는 다른 결과가 나올 수 있습니다.
